AI 중심 재설계

SSD 컨트롤러 SoC를 설계·검증하는 팀의 AI 전환 전략을 소개하는 영상입니다. 본편 한 편과, 본편의 "5대 전환"을 축마다 풀어 쓴 상세 영상 다섯 편, 그리고 구조 설계와 추적성을 깊게 다룬 두 편이 있습니다.

SSD 컨트롤러 SoC AX 전략5:32

수확한 열매와 남은 나무, 병목 이동, Jira로 잇는 추적과 소통, 사례 7단계(구조 설계는 모델 먼저, RTL 설계자는 블록별 예산과 계약을 받음)(요구사항 분석 → 아키텍처 → IP 설계·PPA → 시뮬레이션 검증 → Emulation·FPGA → FW 개발 → 제품 테스트·퀄), 5대 전환, 책임, 3단계 로드맵.

구조 설계 편

요구사항이 크게 바뀔 때 RTL부터 짜는 것이 빠른지, 모델로 먼저 검증하는 것이 빠른지를 예제 하나로 끝까지 따라갑니다.

구조 설계: RTL 먼저 → 모델로 먼저 검증9:16

TLC에서 차세대 QLC로 바뀌는 과제. "RTL 먼저" 경로와 "모델 먼저" 경로의 비교, 후보 구조 4개, 통합 모델 대 목적별 모델(모델은 여럿, 구조 기술은 하나), 여러 관점의 탐색과 제약 판정, 모델이 찾은 GC 경쟁 문제, 결정 기록, RTL 설계자가 받는 예산과 계약, RTL에서 구조로 되돌리는 길, 손익분기점과 판단 기준.
